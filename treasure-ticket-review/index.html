HOW TO START

このサービスは招待制です

URLを知っているだけでは利用できません。TREASURE管理者がジム担当者を招待し、そのジム担当者が所属選手を招待して利用開始します。

STEP 1TREASURE管理者ジム名・担当者メールを登録して招待
→
STEP 2ジム担当者招待メールから登録・住所/口座を設定
→
STEP 3所属選手ジムから招待メールを受け取り登録
重要： 選手が自分で新規登録したり、ジムが勝手にTREASURE管理者になることはできません。完成版では各役割の専用ログイン入口から、自分に付与された権限だけ利用できます。
FIRST TIME GUIDE

初めての方はこちら

難しい操作はありません。自分の役割を選んで、上から順番に進めれば使える設計です。

選手
  1. 所属ジムから招待メールを受け取る
  2. 招待リンクから登録
  3. 選手専用入口でログイン
  4. 券種と枚数を入力・確認
  5. 注文後、ジム確認・発送状況を見る
ジム担当者
  1. TREASUREから招待メールを受け取る
  2. 招待リンクから登録
  3. 住所・担当者・精算口座を登録
  4. 所属選手を招待する
  5. 注文確認・発送・精算を管理する
TREASURE
  1. 管理者専用入口＋MFAでログイン
  2. ジム名・担当者メールを登録して招待
  3. 価格・在庫を設定
  4. 注文・受け渡しを確認
  5. 注文締切後にジム別請求
困った時：ボタンを押すと「保存中…」「更新中…」になり、完了後に画面へ反映します。残枚数以上の注文、注文数以上の受け渡し、請求済み注文の直接取消など、事故につながる操作は止める設計です。
AUTH役割別ログイン＋管理者MFA

選手・ジム・TREASUREを分離。管理者は2段階認証必須の設計。

GYM PROFILE住所・精算口座登録

郵便番号→住所候補、銀行→支店候補。口座番号は通常画面でマスク。

INVENTORY価格・在庫・受け渡し

券種別在庫、興行側確保、ジムへの受け渡し枚数上限を管理。

SETTLEMENTジム単位の精算

注文締切後に最終請求。一部入金→入金済みまで管理。

PRIVACY規約・監査ログ

プライバシーポリシー、利用規約、操作変更履歴を確認。

INVITETREASURE→ジム→選手

一般登録ではなく招待制。完成時は各役割専用入口だけ利用。

テストをやり直すとき

追加注文・ジム確認・発送状態を初期サンプルへ戻します。
