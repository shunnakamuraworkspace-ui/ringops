HOW TO START

このサービスは招待制です

正式運用は招待制です。TREASURE管理者がジム担当者を招待し、ジム担当者が所属選手を招待します。一般公開URLから勝手に登録することはできません。

STEP 1TREASURE管理者ジム名・担当者メールを登録して招待
→
STEP 2ジム担当者招待メールから登録・住所/口座を設定
→
STEP 3所属選手ジムから招待メールを受け取り登録
重要： 選手が自分で新規登録したり、ジムが勝手にTREASURE管理者になることはできません。本番システムでは各役割の専用ログイン入口から、付与された権限だけ利用できます。この画面の役割切り替えは説明用です。
FIRST TIME GUIDE

役割ごとの操作手順

①招待を受け取る → ②登録する → ③専用画面で操作する。下の順に確認してください。

選手
  1. 所属ジムから招待メールを受け取る
  2. 招待リンクから登録
  3. 選手専用入口でログイン
  4. 券種と枚数を入力・確認
  5. 注文後、ジム確認・発送状況を見る
ジム担当者
  1. TREASUREから招待メールを受け取る
  2. 招待リンクから登録
  3. 住所・担当者・精算口座を登録
  4. 所属選手を招待する
  5. 注文確認・発送・精算を管理する
TREASURE
  1. 管理者専用入口＋MFAでログイン
  2. ジム名・担当者メールを登録して招待
  3. 価格・在庫を設定
  4. 注文・受け渡しを確認
  5. 注文締切後にジム別請求
困った時：ボタンを押すと「保存中…」「更新中…」になり、完了後に画面へ反映します。残枚数以上の注文、注文数以上の受け渡し、請求済み注文の直接取消など、事故につながる操作は止める設計です。

よくある質問

困ったときは

招待メールが届かないときは？

迷惑メールを確認し、メールアドレスが正しいかを招待元に問い合わせます。ジム担当者はTREASUREに、選手は所属ジムに連絡します。

チケットの注文を間違えたら？

このデモでは確定前の確認画面で「修正する」を押してください。実運用で確定後の変更が必要な場合はジム担当者へ相談します。請求済み注文は直接取り消せません。

入力した内容は他の端末でも見られる？

この確認ページはブラウザ内のサンプルデータのみ保存します。スマホとパソコンの同期はされません。本番システムではデータベースに保存する設計です。

テストをやり直すとき

追加注文・ジム確認・発送状態を初期サンプルへ戻します。
